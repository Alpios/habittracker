Habit Tracker is a simple application that records and visualizes daily habits using the Pixela API
Uses Python’s requests module to interact with the API efficiently
Setup: (1) sign up at https://pixe.la
       (2) create a user and generate a token, (3) create a graph for tracking habits
Supports core operations: POST (add entry), GET (view data), PUT (update entry), DELETE (remove entry)
Helps users maintain consistency by tracking habits in a clear and visual way over time
